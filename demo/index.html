Basics

1 Top page bar

The classic fixed bar at the top of the viewport. Try the trickle loop and the NProgress-style start() / done() pair.

2 Inline & themeable

Mount a bar anywhere with position: 'inline'. Recolor live — every visual is a CSS custom property. The label updates via labelFormat.

Shapes & positions

3 Circular rings

Set shape: 'circular' for an SVG ring — same full configuration as a linear bar (themes, gradients, glow, persistence, transfers), with a centered live label.

4 Vertical bars

Use position: 'left' or 'right' for a fixed vertical bar. Toggle one fixed to the right edge of the viewport.

Data & integration

6 Upload / download & ETA

Drive a bar from a byte transfer with setProgress(loaded, total), trackXHR() or trackResponse(). The label shows live speed and a smoothed ETA from bar.stats; a failure flips it to the error state.

7 Reactivity

Bind a bar to any value source with bar.bind(getter, { event, target }). This bar follows the slider live.

8 Configure from JSON / API

Drive the themed bar with a JSON config string — the same shape you'd fetch from an API via configUrl / Tabar.fromURL() and report back with reportUrl.

State

9 Many at once

Three independently-configured bars animating concurrently — no id or style collisions, one shared stylesheet. Each shows its live value.

10 Survives a refresh

This bar persists its value to localStorage. Move it, then reload the page — it restores where you left off.

11 Scroll progress

A bottom bar that tracks page scroll. Scroll the page to see it move.

const scroll = new Tabar({ position: 'bottom', color: '#e67e22', trickle: false });
addEventListener('scroll', () => {
  const max = document.documentElement.scrollHeight - innerHeight;
  scroll.set(max > 0 ? scrollY / max : 0);
}, { passive: true });
