Get started

Install, import, and drive a bar around your async work.

Browser
import { Tabar } from '@simtabi/tabar';

const bar = new Tabar({ color: '#29d' });
bar.start();
await fetchData();
bar.done();
Uploads & segments
// live speed + ETA from a fetch download
bar.trackResponse(await fetch(url));

// one bar, many chunks
bar.setSegments([
  { id: 'a', value: 1, weight: 1 },
  { id: 'b', value: 0.4, weight: 3 },
]);
Terminal / CLI
import { terminalBar } from '@simtabi/tabar/node';
const bar = terminalBar({ label: 'Downloading' });
bar.setProgress(loaded, total);

# or pipe progress into the CLI
some-job | npx tabar --total 1000
